# R-CITY-2 adversarial review (road builder, round 4)

Base `7af0a144`; upstream commits 532205ee, 5af967d0, 645f88be, a9a72363, 8f0b467f, bf2357ad, dcb8e80e. No cargo was run.

RC2-01 FIXED - fe-ui/src/node_manager/road_interaction.rs:224 - Undoing a curved or freeform segment pushed N `PathRemovePoint` actions in one batch. A checked remove holds the single undo slot (`undo.rs:536` `ready()`), so only the first landed while the chain log rewound N points. Removals now queue in `RoadBuilderState.pending_removals` (road_chain.rs) and `issue_next_removal` sends one tail removal at a time. It waits while the undo slot is busy and never repeats an unconfirmed one.
RC2-02 FIXED - fe-ui/src/panels/tool_options.rs:686 - The panel's "Undo segment" called `reduce(Backspace)` and dropped the returned `Remove` commits, so the log and anchor rewound but the track kept its points. The reducer now records removals in state, and the viewport system issues them for both the key and the button.
RC2-03 FIXED - fe-ui/src/node_manager/road_chain.rs:299 - Backspace while the create echo was pending (session track unknown) emitted removals that the interaction layer addressed to `editing_track_id`, which is still the previously edited track, so it could delete points from an unrelated track. Undo now waits for the session track, and `can_undo_segment` gates the panel button.
RC2-04 FIXED - fe-ui/src/node_manager/road_chain.rs:320 - Placement during a pending undo would append at indices the queued removals still target. Click, DragSample and DragEnd are ignored until the queue drains.
RC2-05 FIXED - fe-ui/src/node_manager/road_interaction.rs:381 - In Freeform mode, the first press-drag of a road only set the anchor and the stroke was lost. The first press now opens the chain at the press point and starts sampling.
RC2-06 FIXED - fe-ui/src/node_manager/road_interaction.rs:30 - `A` toggled angle snap while also being the camera fly-left key (fe-renderer/src/camera.rs:547), so flying left flipped the snap. Dropped from ROAD_KEYS; the toggle stays in the Options panel. This deviates from spec FR-8 ("A toggles angle snap"), see RC2-15.
RC2-07 FIXED - fe-ui/src/node_manager/road_overlay.rs:216 - The snap-target ring and angle tick used `snap_radius_m` (metres) as a world-unit radius. They are now converted with `meters_to_world` at the petal's map scale.
RC2-08 FIXED - fe-ui/src/node_manager/road_interaction.rs:316 - `sources.candidates()` allocated a fresh Vec every frame while Road was active. It now uses `ForeignSnapSources::candidates_into` and `collect_foreign_anchors_into` (path_point_interaction.rs) with a buffer held in `RoadLocals`.
RC2-09 FIXED - fe-ui/src/node_manager/road_overlay.rs:84 - The Straight and Freeform ghost allocated each frame (`expand_segment`, `decimate`). They now write into the Local buffer (`decimate_into` in road_chain.rs), producing the same points the commit uses.
