# Open project management

This directory is FractalEngine's project-management bundle, published
deliberately as **open project management** (decision D-70, ratified
2026-07-17). It contains the product definition, tech stack, workflow,
strategic roadmap, code style guides, implementation tracks (open under
[tracks/](tracks/), completed under [tracks/_archive/](tracks/_archive/)),
and dated decision records.

Two reading notes for visitors:

- **Working documents, not polished docs.** Tracks carry specs, plans, and
  retros in the state the work actually happened; the live board is
  [tracks.md](tracks.md).
- **The decision register contains drafts.** Entries in
  [tracks/outstanding_decisions_20260715/spec.md](tracks/outstanding_decisions_20260715/spec.md)
  marked `[DEFAULTED]` or without a **RATIFIED** annotation are internal
  deliberations awaiting the project owner's call — they are not settled
  project positions.

Conventions: every markdown file carries OKF frontmatter (`type` required);
each track's `metadata.json` is the machine source of truth for status.
