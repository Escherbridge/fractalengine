2. `Refresh entity access` loads target-scoped effective roles. At `Role to assign for <actual DID>` select
   viewer/editor/manager (Owner additionally has none pin), then use `Assign role <DID>`'s Save role…/Confirm

   independently. Owner rows are separately managed, not ordinary downgrade targets. Verify actual server/
   second-host authority and inherited grants; refreshing/reopening must disarm old confirmations by readback ID.
   Navigation/foreign response/timeout cannot revive the old target or authorize another write before readback.
3. Generate invites for Viewer/Editor/Manager and each1h/24h/7d/30d expiry with a distinct disposable client/identity.
   Use Generate and Copy to Clipboard without capturing the secret-bearing frame. Join through the second host's
   actual Join Verse text field/Join, not an API-only substitute. Private fixture handling may carry the generated
   invite in memory through an explicitly authorized host seam; never log/screenshot/commit it. If no safe transfer

5. In Inspector API Access test role, expiry and client, Generate/dismiss/Copy Token/Copy curl, masked default and

   Curl uses the confirmed runtime listener, not a guessed port/health bearer demo. Use no screenshots
   while a generated token is visible; leave the API tab to clear it before visual capture. API list metadata and
   redacted named controls prove the GUI route; separately verify cryptographic/client/scope behavior through the

   working. Repeat Entity Settings API through `Generate API token for this entry`, `Reveal generated entity API
   token`, `Copy generated entity API token`, `Copy entity scoped API read command` and `Refresh entity API tokens`.
   Confirm own scoped role/expiry/client/revoke; leaving API Access, including programmatic tab changes, clears
   secrets synchronously. Petal read example uses registered nodes GET; Verse/Fractal use scoped query POST.
   Sensitive response artifacts must
