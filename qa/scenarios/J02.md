# Import, edit and inspect a real scene object

Run the [shared procedure](README.md#shared-procedure) first. `F` is bound to this exact owned run; all parameter
names below come from `F info`, the controlled fixture or a freshly inspected UI tree. Complete every current
variant in this journey's coverage matrix, not only the numbered happy path. For each checkpoint record actual
commands, screenshot read/judgment, authoritative assertions, persistence where applicable and new logs in the
current-pass ledger. Missing fixtures are BLOCKED; planned/unrendered routes are audited exclusions until changed.

## User journey

1. Follow [S02](S02-gimbal-move.md) for the original BASIC arrangement and first positive X gimbal proof.
   Record exact fixture node IDs, current transforms and camera. Select Cube 1 by the current sidebar name and
   also by its visible viewport geometry. Empty-space click and Deselect must clear authoritative selection;
   hidden objects must not be picked. Repeat with sidebar selection and compare Inspector refresh.
2. Exercise each Select/Move/Rotate/Scale/Pen/Brush/Measure toolbar button and S/G/R/X/P/B/M shortcut, including repeated-key toggling.
   Read `active_tool` and the visible tool/options, not just button tint. With the latest screenshot locate each
   visible X/Y/Z handle and drag one axis at a time. Record before/after REST transforms; only the intended
   component changes within the interaction's numerical tolerance. Escape during an active drag restores the
   prior value with no DB commit. Capture every axis/tool checkpoint and re-enter the petal to prove persistence.
3. Edit Inspector Position/Rotation/Scale X/Y/Z independently using named fields. Use values (1,2,3), rotation
   (0,15,0) degrees and scale (1.25,1,0.75) on a disposable object; compare UI units and DTO/raw-storage conventions.
   Exercise Apply, Enter and a nonnumeric value separately. Raw SQL storage uses coordinates=[x,z] and elevation=y;
   do not assert a raw three-element position array. Invalid input must neither silently become zero nor commit.
4. Orbit, pan and wheel only over the live viewport. Compare camera fields before/after each intended gesture.
   Scroll Inspector and a floating Data window and assert camera unchanged; J06 repeats layout-specific cases.
5. Open Add GLTF Model, queue a run-local real GLB answer and use the visible Browse/Import path:

   ```powershell
   F dialog-answer fractalengine/assets/samples/info_panel.glb --kind open
   F click --name 'Browse...' --role button
   F ui --interactive
   F click --name 'Import' --role button
   F shot --label j02-import
   F api GET /api/v1/hierarchy
   ```

   Require one new asset-bearing node in this petal and actual rendered geometry. Test typed path/name, malformed
   GLB, cancel, missing path and no-petal form independently. No-op import must not close with false success.
   Ground context Add Empty Node and Add GLTF Model must use the clicked world location and correct parent.
6. Right-click a visible node and use Edit Properties, Rename..., Duplicate, Clear Properties and Delete routes.
   New duplicate ID/transform/data and rename acknowledgement must agree with readback. Use disposable leaf and
   nested objects to test cancel/confirm scope; clearing properties retains the object. Open Node Options and
   compare Save/Cancel/clear/delete parity. Never delete fixture value nodes used by J03 before their oracle.
7. Save webpage/config URLs to the controlled WEB page using named fields, reopen the node and verify durable
   values. Invalid URL must show an error and no false Saved. Open Portal, follow its second local link, Back,
   Close, failure URL and change selected node. Verify renderer/toolbar teardown and no stale webpage overlay.
8. Download the selected asset after queuing save, cancel it, provoke a confined output error and overwrite a
   previously imported input after its read lease releases. Hash the output against the real source bytes, not
   merely file existence. Exercise context Copy API String / Report / Query with no secret-containing capture;
   copy feedback and A8 suppression are separate from actual text generation/BI API outcomes in J03/J09.
9. F028 transform snap/axis lock/undo/redo/F/Delete are planned here; after W2/W4/W5 lands, add concrete enabled
   routes and persisted expected transforms. A placeholder hint or source enum is not successful interaction.
