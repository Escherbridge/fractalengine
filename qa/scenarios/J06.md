## User journey

1. Run [S09](S09-native-dialogs-window.md) and [S10](S10-layout-resilience.md) as focused subjourneys, then cover every
   checkpoint below. Caption minimize/maximize/restore/close and debug chrome requests use the same confirmation;
   verify physical size/window state. Use `Minimize`, `Maximize`, `Restore down`, `Close FractalEngine` to cover
   caption buttons; F window commands cover the API/setup route separately. Caption drag/double-click uses the
   named `FractalEngine title bar`; actual resize grips need their named live
   response bounds; derive drag endpoints from those bounds, never fixed screen guesses. Missing semantic drag
   targets are accessibility findings. Do not move the real OS cursor or act on any other window.
2. Cancel close and confirm close in a terminal run; dirty manifest reason must be accurate. Confirm-close runs
   LAST for that root. Keep exact PID/start/exe identities and inspect final exit/children with the owned stop
   helper. A slow child cleanup failure must be recorded honestly; eventual absence is separate from clean stop.
3. Toggle hierarchy and Ctrl+B; at narrow widths open compact Tools/Panels/Deselect and compare the same actions
   with the wide toolbar. Open every Inspector, Options, Terrain tools, Volume report, Settings, Maps, Groups and
   Data surface; distinguish toggle from RevealSection. Existing selection must survive divider and overlay presses.
4. In Settings change render distance, mesh budget, entity cap and stamp ceiling with known finite values. Check
   actual residency limits and durable configuration, not just a moved slider. Change orbit sensitivity/zoom speed,
   relay and registry values, including invalid URLs; verify save/restart feedback. Exercise Mirror/Sharded/Balanced,
   durability R mode limits and bucket presets/numeric entry, reading the actual verse settings after commit.
5. Check info/advisory/error notices, lasting error/history, role/budget/peer segments and populated scene counters.
   Generate a controlled invalid action, then a success; success must not silently erase the important failure.
   Verify bounded role-chip wrapping and compare nonzero scene counters with independently known fixture contents.
   A source fix is not visual verification, and a newly active scope must not inherit stale counts. Do not provoke
   a panic to test quarantine in a panic=abort production app; its safe recovery seam remains planned. Open
   `Open keyboard and pointer help`, verify current actual tool/camera/visibility/Undo chords, then close the popup
   by its documented outside-click/Escape path. No fake Pivot/filter/help commands may be promised.
6. Exercise each real open/save/folder site, cancellation, empty queue, wrong kind, traversal/junction/ADS/reserved
   device/drive-relative refusal and atomic multi-answer admission. Verify rejected batches leave old answers intact,
   paths stay in the run, frames do not block and completed input leases release for later overwrite. Native picker
   behavior with input off is a separate normal-app acceptance case, never a QA-provider fallback.

   all tool Options arms, map tabs, entity settings tabs, token empty/populated states, path/annotation/egress, close
   and delete confirmations. Use actual long paths/names, UI scale1.25 and the compact640×480/scale2 edge case:


   Scroll unknown controls into view, open dropdown/color-picker children and inspect real hit rectangles/text.
   Require protected viewport share>=45% under supported budget, reachable footer, ellipsis/full hover and no off-window
   controls. A zero measured count with unknowns cannot establish complete layout coverage. An otherwise tested
   feature need not fail solely because an unrelated text observation is unknown; name the exact uncovered variant.
8. Repeat Inspector/viewport/floating Data wheel isolation. In every text field type B/G/R/X and Enter with proper
   focus; camera/tool must not change unexpectedly. Exercise Escape's active gesture, solo, path edit, selection,
   tool, context-menu and modal rungs independently. Compare state before/after each rung, not a chain of blind Escapes.
9. At ppp2 verify strict divider grab-radius endpoints from the final S6 recipe: select a node, read actual panel/
   dock divider geometry and radius, press/drag exactly at left+radius/right-radius/dock-top-radius, require selection
   unchanged. Then genuine viewport node and empty-space clicks must still select/deselect. Convert points to
   screenshot pixels once. Do not confuse visual ViewportRect with the smaller interaction rectangle.
10. In a separate disposable owned root, open Settings Danger zone. The trusted developer gate hides it when
    disabled; a host without the terminal sender shows an honest disabled reason. Type exact `RESET` in
    `Database reset confirmation`; wrong case/partial text must not enable the request. Exercise first-click
    arm, Cancel and target/navigation changes before final `Confirm Reset local database`. Compare unchanged
    stored contents after cancellation. Record scope copy accurately: content/history/token records clear,
    identity/preferences/packages/blobs remain, peers are not erased, and manual Close/reopen is required.
11. After actual confirmation, inspect quiescence progress and the terminal UI. The API must stop, plugin leases
    revoke, every named service join, finite jobs drain, dev-token publication stop and the EntityStore reach
    unique ownership before the final serial command. Preserve the bounded status receipts and exact process
    identities; missing API after shutdown is not itself a successful clear. Require the matching committed DB
    receipt AND its joined worker. No old editor, scene/URL/token cache or delayed result may repopulate state;
    a queued post-barrier mutation must not execute. Actual failure/timeout remains terminal and unconfirmed
    without retry or automatic reconnection. Close manually and reopen the same disposable store, then compare
    default seed, retained identity/preferences/blob hashes and all reset table contents against the oracle.
12. Through the existing controlled real-store/lifecycle journeys, separately exercise foreign/ambiguous global
    ownership, unknown tables, failed joins, full bounded result queues, running finite jobs, missing DB receipt,
    late writes and seed failure. Each must either refuse before clear or report its exact unconfirmed/cleared
    outcome; never fabricate a success from a stop request. J09/F142 separately proves that a confirmed reset
    rotates credential generation atomically: a saved old valid Owner credential must fail after manual reopen,
    while a fresh credential from the same retained signing key works. Keep credential bytes only in memory.
    Never reset the retained campaign root or replace a missing native GUI action with an internal reset call.
