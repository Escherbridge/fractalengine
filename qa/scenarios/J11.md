# Install, share and roundtrip real content packages

Run the [shared procedure](README.md#shared-procedure) first. `F` is bound to this exact owned run; all parameter

## User journey

1. Open Maps Installed/Available/Downloads, filter, Refresh and Close. Each needs populated/empty/error/progress
   states with actual provider data; an empty Available list does not cover Download. Use the deterministic S7
   archive/config and [S04](S04-petal-map-terrain.md) to establish real terrain. Verify hashes and real registry rows.
2. Queue open and Install from file a valid TerrainTileset, cancel it, reject legacy Terrain/wrong-kind and corrupt
   archives. Require one correct installed row or a typed refusal without partial installation. Never relabel an
   incompatible archive to manufacture a fixture. Bind the installed source to a disposable petal and inspect
   actual plane/hill; registry row existence is not rendering proof.
3. Start a controlled run-local registry/provider exposing the tiny valid archive with known hashes/metadata.
   Set Registry URI and Install from registry via UI, then exercise unavailable lookup and hash mismatch. Record
   the owned provider PID/start/exe and exact cleanup. Missing controlled provider is BLOCKED; public internet
   luck is not a deterministic success fixture. Do not silently edit production settings outside the owned root.
4. Download from Available and inspect real bytes/progress in Downloads, then Cancel a second controlled slow
   download. Compare complete bytes/hash and absence of false installed success for cancel. Controlled chunking/
   delay is a fixture prerequisite. Verify resumed/partial behavior only where exposed, with explicit source/hash.
5. Toggle Seed on/off, open the run-local folder through the supported folder seam, and Remove-cancel/confirm.
   Exercise active-map removal safety, not just removal of an unused row. Confirm registry/config/actual terrain
   remain consistent after each case, and input/output path leases release after their operations.
6. Open Petal Manifest, add a real ID/type/Required row, remove another, inspect JSON and Save. Reload the persisted
   requirements and compare exact arrays/types. Close clean, cancel dirty close and confirm discard separately.
   Duplicate render-distance editing is planned for removal in W2; test current behavior honestly, then refresh
   catalog when that field disappears. Manifest dirty-state loss cannot be hidden by closing another dialog.
7. Roundtrip a real GLB by bytes/hash, GPX by parsed CRS-correct coordinate arrays and `.hexon` through actual export/
   import/bundle/assemble/readback. UI open/save actions belong to their GUI cases; API corroboration cannot replace
   those controls. File existence alone is never an interoperability oracle. Use disposable scopes for import.
8. Plugin/Rhai read and transaction execution is library/API-only, with actual existing harness/client and committed
   data readback; W6 improves that seam without inventing a desktop plugin panel. Atlas tag/model/room helpers have
   no production opener established; F127 stays audited U until a real route is wired. Do not add an unreachable
   helper to the GUI denominator merely because its source contains widgets.
