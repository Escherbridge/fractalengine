## User journey

1. Copy the real sample.gpx into the owned run, queue open and click Import GPX... through Data/Paths. Read the
   projected track against independently parsed source latitude/longitude/elevation. Test malformed and cancel;
   neither may leave a partial/duplicate track. Create New Path through UI, select/edit it, Back, and cancel/confirm
   deletion on a second disposable track. Track IDs/selection/stamps must stay consistent.
2. Press P and use viewport click for a corner, drag for smooth and Alt-drag for symmetric anchors. A deferred
   automatically created track must appear only once. Use three noncollinear points with recorded world positions.
   Assert durable gpx_points and handle geometry after every commit, not only a visually similar line.
3. Select Polyline, Catmull-Rom and Bezier; vary tension/samples and Smooth path, with one visible geometry
   checkpoint each. Compute expected endpoints/count/curvature from the known points rather than pixel appearance
   alone. No-track disabled state is a separate case. Exercise new/selected Corner/Smooth/Symmetric and smoothness;
   inspect tangent/handle constraints after a handle drag.
4. Set Radius X/Z and Segments, then Add Ellipse, Circle and Rectangle on disposable tracks. Check closed geometry,
   dimensions and vertex count. Exercise no-track guard. Point selection, Y edit, Remove, Annotate, point drag,
   handle drag and segment drag each target the correct index; drag release must issue one durable commit rather
   than a command for every pointer move. API/DB trace evidence is needed for that release-count assertion.
5. Annotate one point with title/body/color and Save, then Cancel another annotation. Require one waypoint at the
   actual anchor and none for cancel. Change border color/width, Closed zone and fill color/alpha; verify rendered
   ribbon/fill and gis.track.* persistence. Enable snapping/grid/anchor radius and use whole-path gimbal; compare
   metric positions and transformed point arrays after re-entering the petal.
6. In path assets filter and select the real installed GLB, clear it, enter its blob:// URI manually and check a
   missing URI's refusal. Stamp with Fixed count3, then a separate known-length path with Fixed spacing. For a
   straight10m path and spacing2m compare the implementation's documented endpoint inclusion with an independently
   enumerated sequence; record that contract before the action, not after observing its result. Toggle tangent
   alignment and verify orientation from the path tangent. Read the path_asset descriptor plus actual instances.
7. Select a materialized stamp through its actual lower-tier viewport pick, freshly classified context pick,
   and Options `Stamp number to select (one-based)` / `Select the rendered stamp number`, separately. Visible
   Stamp2 must resolve instance index1 of the exact rendered path. Keep F10 point/handle/edited-ribbon priority:
   clicking an edited ribbon still selects the path; the explicit selector is the intended escape, not a new
   picker priority. Hidden, missing, reflowed, wrong-Petal or pre-restamp old-source entities must refuse.
   Compare its actual node/address/instance identity. Viewer selection performs no promotion or property write;
   Editor selection queues the captured checked promotion. Only the matching confirmed receipt may bind the
   durable `path#inst-index` address to the same selected entity. The synthetic rendered marker is not a stored
   node and must not trigger Inspector reads. `Inspect selected editable stamp node` reveals the already bound
   target. Edit `Selected stamp X/Y/Z
   scale multiplier`, `Selected stamp yaw in degrees`, `Selected stamp distance along path in meters`, then
   `Apply all stamp changes` once. Require one checked atomic receipt covering the entire override batch, pending
   status and exact stored readback. `Reload selected stamp values` performs an actual read. Check a curved path,
   nonunit map scale, existing nonuniform axes/full quaternion and out-of-range legacy values: untouched rotation/
   axes persist, meters convert once through the shared sampler, render/focus/blur never silently clamps input,
   invalid drafts disable Apply. `Inspect selected editable stamp node` changes inspected target, not parent.
   Repeat current context Promote/Scale-Rotate/Slide/Delete and compare other instances/track remain intact.
   Queue selection and Apply, then change actual descriptor/points/Petal/selection generation before use: no
   replacement instance may receive that intent. Different objects, path point/segment selection and Petal
   changes clear the projection. Lose Editor after dispatch, then regrant before the old receipt arrives:
   the request stays invalid and cannot hydrate or bind. Loss of all view access clears queued requests and
   both catalog mirrors; only an explicit fresh authorized selection may resume. Retain Viewer read-only
   inspection of an existing promoted node as a separate case from first selection requiring promotion.

   Through the existing real-store preparation/commit journey, mutate actual role, ancestry, descriptor/raw
   point order, map, history tail, target identity or enforced creation schema between capture and use; each
   must refuse without row/operation changes. Induced operation failure rolls back creation. Re-selecting an
   existing exact stamp returns confirmed full properties without a new promotion operation. Renderer and DB
   must agree on degenerate paths, spacing/count endpoint rules and the4096 bound through the shared sampler.
   Public REST/MCP `promote_instance` retains its separate caller-current-index contract; invoking that API
   does not exercise the GUI's captured-origin producer or its private checked DB adapter.
8. At `Point <one-based number> corner kind: Corner/Smooth/Symmetric` and `Point <number> smoothness`, retain the
   original route across pointer frames. Numeric point-height Enter/blur and slider release each emit one checked
   mutation; intermediate text, focus-only frames and idle redraw emit none. Context Corner/Smooth/Remove captures
   the classified point before clicking. Change/reorder route or navigate while open, then click: no write may
   target the replacement point. Known failure/late reply never projects optimistic geometry or recreates a target.
   Remove uses the timed Confirm/Cancel scoped to navigation/track/content. Compare complete stored points/handles.
